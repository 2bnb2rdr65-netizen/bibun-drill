基礎知識と公式まとめ

微分とは

グラフのある点での傾き（変化の速さ）を求めることです。d/dx f(x) は「x を少し増やしたとき、f(x) がどれだけ増えるか」の割合を表します。

例：y = x² の x = 3 での傾きは、微分した 2x に x = 3 を入れた 6 です。物の位置を微分すると、速さになります。

積分とは

微分の逆の操作です。微分すると f(x) になる元の関数を探します（不定積分）。もうひとつの顔として、グラフと x 軸の間の面積を求める道具でもあります。

例：x² を微分すると 2x になります。だから 2x を積分すると x²（＋ C）です。速さを積分すると、進んだ距離になります。

積分定数 C

x² + 1 も x² − 5 も、微分するとどちらも 2x になります（定数は消えるため）。そのため 2x の積分は「x² に何か定数を足したもの」としか言えず、+ C と書きます。

xⁿ（べき乗）

xⁿ は x を n 回掛けたものです（x³ = x·x·x）。x¹ = x、x⁰ = 1 と決めます。

微分は、指数を前に出して 1 下げます（x⁴ → 4x³）。積分は、指数を 1 上げて、新しい指数で割ります（x³ → x⁴/4）。

n = −1（つまり 1/x）だけは、新しい指数が 0 になって割れないため、この公式が使えません。代わりに ln|x| を使います。

定数

x を含まない数（例：7）のことです。x が変わっても値が変わらないので、グラフは水平で傾きは 0。微分すると 0 になるのはこのためです。積分すると c·x（傾き c の直線）になります。

sin x と cos x

円の上を回る点の高さ（sin）と横位置（cos）を、角度 x（ラジアン）の関数として見たものです。どちらも −1 から 1 の間を行き来する波の形をしています。cos x のグラフは、sin x を左にずらした形です。

微分すると、次の順にぐるぐる回ります。
sin x → cos x → −sin x → −cos x → sin x → …
積分は、この逆向きに回ります。マイナスの付け忘れが多いのは、cos x の微分と sin x の積分です。

eˣ（指数関数）

e はネイピア数と呼ばれる定数で、e ≈ 2.71828… です（π のように、小数が終わらない数）。eˣ は「e を x 回掛けたもの」です。

e の由来：年利 100% の預金を、1 年を n 回に分けて複利で増やすと (1 + 1/n)ⁿ 倍になります。n を大きくしていくと、この値は e に近づきます。

eˣ の大きな特徴は、どの点でも、グラフの傾きがその点の高さと同じになることです。x = 0 では高さ 1 で傾き 1、x = 1 では高さ e で傾き e。だから微分しても積分しても、eˣ のまま変わりません。

増える速さが「今の量」に比例するもの（人口の増加や複利など）を表すときに、よく出てくる関数です。

ln x（自然対数）と 1/x

ln x は eˣ の逆の関数です。「e を何乗したら x になるか」に答えます。たとえば ln e = 1、ln 1 = 0（e⁰ = 1 だから）です。x > 0 のときだけ使えます。

ln x を微分すると 1/x になります。逆に、1/x を積分すると ln|x| です。絶対値の記号は、x が負のときにも使えるようにするためのものです（1/x は x < 0 でも存在するため）。

合成関数（中身がある関数）【中級】

関数の中に、別の式が入っている形です。例：(2x + 1)³、sin(3x)、e2x、ln(x + 4)。カッコや指数の中身を u とおいて考えます。

微分：外側を微分して、中身の微分を掛けます。

(uⁿ)′ = n·uⁿ⁻¹·u′　(sin u)′ = cos u·u′　(eu)′ = eu·u′　(ln u)′ = u′/u

例：(2x + 1)³ は、外側を微分した 3(2x + 1)² に、中身の微分 2 を掛けて 6(2x + 1)² です。

積分（中身が ax + b の1次式のとき）：外側の積分をして、a で割ります。微分のときに掛けた a を戻すためです。

例：∫e3xdx = ⅓e3x + C。この割り算を忘れるのが、よくあるミスです。

確かめ方：答えを微分して、「外側の微分 × 中身の微分」で元の式に戻るか見ます。

マイナスの指数とルート【中級】

分母にある x は、指数にマイナスを付けて書きかえられます。1/xⁿ = x−n。また、ルートは 1/2 乗です。√x = x1/2。

こう書きかえると、xⁿ の公式がそのまま使えます。n がマイナスでも分数でも、公式は同じです。

微分の例：1/x² = x−2 → −2x−3 = −2/x³。√x = x1/2 → ½x−1/2 = 1/(2√x)。

積分の例：∫x−2dx = x−1/(−1) = −1/x。∫√x dx = x3/2/(3/2) = ⅔x3/2。分数で割るときは、逆数を掛けます。

注意：n = −1（つまり 1/x）の積分だけは、新しい指数が 0 になるため使えません。ln|x| になります。

積の微分【上級】

2つの関数が掛け算になっているとき、「掛けたものの微分」は、「それぞれの微分の掛け算」にはなりません。

(uv)′ = u′v + uv′

「片方だけ微分した項」を、2つ足します。例：(x·eˣ)′ = 1·eˣ + x·eˣ = (x + 1)eˣ。

よくあるミスは、両方を微分して u′v′ としてしまうことです。

商の微分【上級】

割り算の形の関数の微分です。

(u/v)′ = (u′v − uv′) / v²

分子の順番とマイナスに注意してください（u′v が先です）。例：(sin x / x)′ = (x cos x − sin x) / x²。

分母が x のべきだけなら、x−n を掛けた積として、積の微分で解くこともできます。

置換積分【上級】

中身が複雑な積分を、中身を u とおいて簡単な積分に直す方法です。「ある関数」と「その中身の微分」が一緒に入っている形が目印です。

手順：① 中身を u とおく　② du = u′dx を作る（x dx などを du で置きかえる）　③ u で積分する　④ u をもとの式に戻す。

例：∫2x·ex²dx。u = x² とおくと du = 2x dx。∫eudu = eu = ex² + C。

例：∫x·ex²dx は、du = 2x dx から x dx = du/2。½∫eudu = ½ex² + C。

部分積分【上級】

積の微分の逆から作られた、掛け算の積分の公式です。

∫u v′ dx = uv − ∫u′v dx

u は微分、v′ は積分します。残った積分が元より簡単になれば成功です。u は「微分すると簡単になるほう」（x や ln x）、v′ は「積分しやすいほう」（eˣ、sin x、cos x）を選びます。

例：∫x·eˣdx。u = x、v′ = eˣ とすると、u′ = 1、v = eˣ。xeˣ − ∫eˣdx = (x − 1)eˣ + C。

ln x の積分は、v′ = 1 とみなして、u = ln x、v = x で解きます。結果は x ln x − x + C です。
